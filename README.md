# YAAAS
YAAAS (Yet another AI Audio Syncer) is a python script to automatically find, download and/or sync lyrics, by downloading them from LRCLIB, and then syncing them to word by word using WhisperX.
# Why did I make this?
Because there's so many vibecoded projects that do the same thing, but are full of errors, misuse storage space and hardware, and are so fragmented, I decided to make a definitiveX final "One to rule them all" software.
